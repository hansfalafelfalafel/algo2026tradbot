# Карта экспериментов

Скрипты пронумерованы в том порядке, в котором развивался проект. Нумерацию я сохранила специально: по ней удобно восстановить ход исследования — от первых RL-моделей до микроструктуры, проверки на новых данных и песочницы брокера.

| Этап | Скрипты | Что в них происходит |
|---|---|---|
| Базовая версия проекта | `00–11` | поиск инструментов, загрузка данных, обучение RL-моделей, backtest, песочница, ансамбль и walk-forward |
| Альтернативные стратегии | `20–26` | парный арбитраж, momentum, meta-labeling |
| Микроструктура рынка | `30–42` | сбор стакана, расчёт OFI, моделирование исполнения, учёт издержек, AlgoPack, градиентный бустинг и GRU |
| Проверка на новых данных | `43–54` | forward-оценка, разбор причин ухудшения результата, фиксация MR30, исследование рыночных режимов |
| Песочница брокера | `55–58` | запуск MR30 через T-Bank Sandbox, журнал сделок, статистика и уведомления |
| Устойчивость и новые гипотезы | `59–73` | сравнение MR и momentum, walk-forward, режимные фильтры, ML-фильтры сигналов, Triple Barrier, чувствительность к издержкам, переключение режима |

Эти скрипты не нужно запускать подряд от `00` до `73`. Часть из них — отдельные исследовательские ветки. Они сохранены, чтобы можно было воспроизвести конкретный эксперимент и понять, почему следующий этап проекта появился именно после него.
