# С чего начать: пошаговая инструкция

Инструкция для запуска на **обычном рабочем компьютере**, без своего сервера.
Отдельного сервера для старта не нужно — обучение и тесты прекрасно считаются на
ноутбуке (нужен только процессор, видеокарта необязательна). Сервер (аренда VPS)
понадобится позже — только если захочешь, чтобы бот и дашборд работали
**круглосуточно сами по себе**. Про это — в конце.

---

## Часть 1. Установка (один раз, ~15 минут)

**Шаг 1. Установи Python 3.11.** Проверь в терминале:

```bash
python --version      # должно быть 3.9–3.11
```

Если нет — скачай с python.org (Windows: при установке отметь «Add Python to PATH»).

**Шаг 2. Распакуй проект и зайди в папку:**

```bash
cd rl-trading-tbank
```

**Шаг 3. Создай виртуальное окружение и активируй:**

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
```

**Шаг 4. Установи зависимости:**

```bash
pip install -r requirements.txt
```

**Шаг 4б. Установи SDK Т-Банка отдельной командой** (актуальный официальный
пакет `t-tech-investments`, импорт `t_tech.invest`):

```bash
pip install t-tech-investments --index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple
```

Код проекта совместим с новым SDK автоматически — слой совместимости в
`src/__init__.py` подменяет `tinkoff.invest` на `t_tech.invest`, править ничего
не нужно.

**Шаг 4в (для Linux-сервера). Корневые сертификаты НУЦ Минцифры.** Сертификат
сервера Т-Банка подписан российским корневым CA, которого нет на чистом сервере —
без него будет ошибка `CERTIFICATE_VERIFY_FAILED`. Установи (под root):

```bash
apt-get update && apt-get install -y wget ca-certificates
wget -O /usr/local/share/ca-certificates/russian_trusted_root_ca.crt https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
wget -O /usr/local/share/ca-certificates/russian_trusted_sub_ca.crt  https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt
update-ca-certificates
```

Проект сам направит gRPC на системное хранилище сертификатов (это делает
`src/__init__.py`). На Windows/macOS этот шаг обычно не нужен.

**Шаг 5. Получи токен Т-Банка** (приложение Т-Банк Инвестиции → Ещё → Настройки
→ Токен для Invest API). Скопируй шаблон секретов и впиши токен:

```bash
cp .env.example .env          # Windows: copy .env.example .env
# открой .env в блокноте и вставь:  TINKOFF_TOKEN=твой_токен
```

## Часть 2. Обучение и проверка модели (по шагам)

Всё запускается из папки проекта. Порядок:

```bash
# 1. Найти FIGI нужных бумаг (уже прописаны SBER/GAZP/LKOH, но можно менять)
python scripts/00_find_instrument.py SBER

# 2. Скачать историю котировок (сохранится в data_cache/)
python scripts/01_download_data.py

# 3. Собрать новостной сигнал
python scripts/05_fetch_news.py            # реальные новости
#   или без интернета для пробы:
python scripts/05_fetch_news.py --sample

# 4. ОБУЧИТЬ ансамбль (PPO+SAC+A2C). Это главный шаг. ~10–40 мин на ноутбуке.
python scripts/06_train_ensemble.py

# 5. Проверить на отложенных данных (метрики + график)
python scripts/07_backtest_portfolio.py

# 6. Честная проверка на переобучение (walk-forward + PBO) — дольше
python scripts/11_walkforward.py --folds 4

# 7. Получить рекомендацию «портфель на сегодня» + отправить в Telegram
python scripts/08_recommend.py
```

Хочешь быстрее прогнать обучение для первой пробы — открой `config.yaml` и
уменьши `agent.total_timesteps` (например, до 20000).

## Часть 3. Дашборд и Telegram

**Дашборд** (в отдельном окне терминала, окружение тоже активируй):

```bash
streamlit run dashboard/app.py
```

Откроется в браузере по адресу http://localhost:8501 — вкладки Обзор,
Аналитика (DS), Прогноз, Управление.

**Telegram.** Создай бота у `@BotFather`, узнай свой chat_id у `@userinfobot`,
впиши в `.env`:

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Теперь `python scripts/08_recommend.py` пришлёт рекомендацию в Telegram.

**Расписание** (каждое утро/вечер сам присылает портфель). Времена — в
`config.yaml -> schedule.daily_times`. Держи запущенным:

```bash
python scripts/10_scheduler.py
```

## Часть 4. Живая торговля в песочнице

```bash
python scripts/09_run_live.py            # обычный цикл
python scripts/09_run_live.py --stream    # быстрая реакция (стриминг котировок)
python scripts/09_run_live.py --once       # один проход для проверки
```

Режим (`manual` / `semi` / `auto`) и все лимиты — в `config.yaml -> execution`
и меняются на лету во вкладке «Управление» дашборда. По умолчанию `manual` —
бот только предлагает, ты подтверждаешь сделки кнопкой. Это самый безопасный
старт.

## Часть 5. Где это запускать: компьютер или сервер?

**Для обучения, тестов, бэктеста, разовых рекомендаций — хватает твоего
компьютера.** Ничего арендовать не нужно. Запустил, посчиталось, посмотрел.

**Сервер (VPS) нужен только для режима «24/7 без твоего участия»:** чтобы
`09_run_live.py` и/или `10_scheduler.py` работали круглосуточно, даже когда
компьютер выключен. Варианты:

1. **Пока не арендовать ничего.** Запускать live-цикл и дашборд на своём
   компьютере в те часы, когда он включён. Для учёбы/диплома и первых
   экспериментов этого достаточно.
2. **Арендовать дешёвый VPS** (например, у российского хостера, 1–2 vCPU, 2 ГБ
   RAM — этого хватает, GPU не нужен). Порядок действий:
   - взять Ubuntu-сервер;
   - повторить установку из Части 1;
   - скопировать обученные модели из папки `models/` (или обучить на сервере);
   - запустить `10_scheduler.py` и/или `09_run_live.py` внутри `tmux`/`screen`,
     либо оформить их как systemd-сервисы, чтобы автозапускались;
   - дашборд поднять командой
     `streamlit run dashboard/app.py --server.address 0.0.0.0` и открывать по IP
     сервера (закрыв доступ паролем/файрволом).

**Рекомендация:** начни на своём компьютере в режиме `manual`. Убедись, что
логика и рекомендации адекватны на песочнице. Аренду сервера подключай только
когда захочешь автономную работу — переезд займёт полчаса по инструкции выше.

## Могу ли я (ассистент) обучить модель за тебя?

Частично да. Обучающий конвейер уже проверен на тестовых данных на стороне
ассистента. Но для обучения на **реальных** котировках MOEX нужен твой личный
токен Т-Банка (его нельзя передавать в чат из соображений безопасности).
Рабочий вариант совместной работы: ты запускаешь только шаг загрузки данных
(`01_download_data.py`) у себя — он создаёт CSV-файлы в `data_cache/` — и
присылаешь эти CSV; тогда обучение, бэктест и прогноз можно прогнать за тебя и
вернуть готовые модели и отчёты. Либо просто выполни шаги Части 2 сам — они
рассчитаны на обычный компьютер.
