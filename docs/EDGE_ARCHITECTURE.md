# MOEX-EDGE: архитектура для поиска устойчивого преимущества на MOEX

Цель — не «волшебная модель», а система, устроенная как у систематических фондов:
**несколько независимых источников слабого преимущества + ML-фильтр качества
сигналов + жёсткий риск-контур + честная валидация.** Это сложный и трудозатратный
путь; гарантий прибыли нет ни у кого, но каждый блок ниже опирается на
опубликованные эмпирические результаты, а не на маркетинг.

## 0. Что мы уже узнали (наш собственный эмпирический фундамент)

1. Направленный RL на часовых свечах ликвидных акций — устойчиво убыточен OOS.
2. Парный арбитраж на свечах (часы и дни) — OOS около нуля: in-sample edge не
   переносится.
3. Вывод: **в свечах ликвидных акций MOEX почти нет извлекаемой информации.**
   Значит, преимущество нужно искать (а) в других данных, (б) в других горизонтах,
   (в) в фильтрации сигналов, а не в генерации «ещё одного» сигнала из тех же цен.

## 1. Три источника edge (по литературе), из которых собираем систему

### Слой A — микроструктура: дисбаланс потока заявок (горизонт: секунды–минуты)
Самый доказанный источник краткосрочной предсказуемости — **order flow imbalance
(OFI)**: перекос между покупками и продажами в биржевом стакане статистически
предсказывает движение цены на коротких горизонтах (Kolm, Turiel, Westray «Deep
Order Flow Imbalance», Mathematical Finance 2023; обзоры deep-LOB-моделей).
Ключевое отличие от свечей: **это данные, которых нет у большинства участников** —
их надо собирать самому, в реальном времени. Это и есть «труднозатратный» edge:
кто собрал датасет стакана — у того есть то, чего нет у толпы.

- Что делаем: коллектор пишет стакан (depth 10) и ленту сделок по всем нашим
  инструментам через стриминг Invest API — 24/7, в файлы по дням.
- Признаки: OFI на нескольких уровнях, микроцена, спред, глубина, скорость потока.
- Модель: сначала логистическая регрессия/градиентный бустинг (быстро и честно),
  затем — RL для тайминга исполнения.
- Срок: сигналу нужно **2–3 месяца накопленных данных**. Поэтому коллектор
  запускаем СЕГОДНЯ — он критический по времени, остальное строится параллельно.

### Слой B — медленные факторы: моментум + volatility targeting (горизонт: недели–месяцы)
Кросс-секционный и time-series **моментум** — самая устойчивая аномалия в
академической литературе (AQR «Explanations for the Momentum Premium»; Quantpedia),
и он **подтверждён на российском рынке** (исследование моментум-эффекта в ликвидных
акциях РФ, 2023). Поверх — **volatility targeting**: масштабирование позиции по
обратной волатильности документированно улучшает Шарп и режет хвосты (Man Group
«The Impact of Volatility Targeting», 2019; Conditional Volatility Targeting, FAJ
2020). Это скромный, но живучий edge: мало сделок, низкие издержки — то, что
реально работает у розничных систематиков.

- Что делаем: месячный/недельный ребаланс портфеля 30–40 акций по моментум-скору,
  позиция ∝ 1/волатильность, тренд-фильтр по индексу (уход в кэш в медвежьем
  режиме — наши же данные показали, что кэш в обвал лучший актив).

### Слой C — мета-лейблинг: ML решает, КАКИМ сигналам верить (главная роль ML)
Урок наших неудач: ML плохо *генерирует* направление, но хорошо *фильтрует*.
Подход Лопеса де Прадо: базовая стратегия даёт сигналы, разметка — **triple-barrier**
(тейк/стоп/время), а ML-модель предсказывает **вероятность успеха каждого сигнала**
и его размер. Независимая проверка (Hudson & Thames «Does Meta-Labeling Add to
Signal Efficacy?») показывает системное улучшение точности и Шарпа. Здесь же живёт
его список «10 причин, почему ML-фонды проваливаются» — мы уже соблюдаем главные
(walk-forward, PBO, издержки).

- Что делаем: все сигналы слоёв A и B проходят через мета-модель (бустинг на
  признаках режима, волатильности, новостного фона, качества сигнала). Торгуются
  только сигналы с P(успех) выше порога; размер ∝ вероятности.

## 2. Общая схема

```
   ДАННЫЕ                     СИГНАЛЫ                    РЕШЕНИЕ
┌──────────────┐   ┌─────────────────────────┐   ┌──────────────────────┐
│ Стакан+лента │──▶│ A: OFI-модель (сек–мин) │──▶│                      │
│ (свой сбор!) │   ├─────────────────────────┤   │  МЕТА-ЛЕЙБЛИНГ:      │
│ Свечи (5 лет)│──▶│ B: моментум+vol-target  │──▶│  ML-фильтр сигналов  │
│ Новости/сент.│──▶│    (недели)             │   │  (P успеха, размер)  │
│ Индекс MOEX  │──▶│ Режим рынка (тренд/vol) │──▶│                      │
└──────────────┘   └─────────────────────────┘   └─────────┬────────────┘
                                                            ▼
                                              ┌──────────────────────────┐
                                              │ РИСК-КОНТУР (есть):      │
                                              │ vol-targeting, лимиты,   │
                                              │ kill-switch, manual/auto │
                                              └─────────┬────────────────┘
                                                        ▼
                                              ┌──────────────────────────┐
                                              │ ИСПОЛНЕНИЕ: лимитные     │
                                              │ заявки, песочница → счёт │
                                              └──────────────────────────┘
   ВАЛИДАЦИЯ ВСЕГО: walk-forward + PBO + deflated Sharpe (уже построены)
```

## 3. Почему «обыграть большинство трейдеров» — реалистичная формулировка

Большинство розничных трейдеров теряют деньги из-за переторговли, комиссий и
эмоций. Система выше выигрывает у них не «предсказанием будущего», а: низкими
издержками (слой B почти не торгует), выживанием в обвалах (режимный фильтр +
vol-targeting + kill-switch), отсутствием эмоций и честной статистикой (PBO).
Обыграть *рынок* сильно и стабильно — не обещаю. Обыграть *большинство
участников* — задача про дисциплину и риск, и она решаема.

## 4. Поэтапный план (8–10 недель, с kill-критериями)

| Этап | Что | Срок | Критерий продолжения |
|---|---|---|---|
| 1 | Коллектор стакана+ленты запущен 24/7 | сегодня | данные копятся без дыр |
| 2 | Слой B: моментум+vol-target, бэктест 5 лет, walk-forward | 1–2 нед | OOS Sharpe > 0.5, просадка < B&H |
| 3 | Мета-лейблинг поверх B (triple-barrier + бустинг) | 2–3 нед | прирост Шарпа vs слой B |
| 4 | Песочница: слой B+C в manual/semi режиме | параллельно | месяц бумажной торговли в плюс к B&H |
| 5 | Слой A: OFI-модель на накопленном стакане | после 2–3 мес данных | AUC > 0.55 OOS, после издержек > 0 |
| 6 | RL: тайминг/размер поверх мета-сигналов | после этапа 3 | прирост vs этап 3 |

Каждый этап имеет kill-критерий: не прошёл — не тащим дальше, честно фиксируем.
