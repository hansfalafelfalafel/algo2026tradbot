# algo2026tradbot
algotrading bot on python
# Разработка интеллектуальной системы алгоритмической торговли акциями и фьючерсами с использованием методов обучения с подкреплением

Выпускная квалификационная работа. Репозиторий содержит полную программную
реализацию системы и результаты экспериментального исследования на реальных
данных Московской биржи.

## Аннотация

Разработана программная система для построения, обучения и честной проверки
алгоритмических торговых стратегий на российском фондовом рынке. Система
включает: подключение к брокерскому API (Т-Банк Инвестиции) и биржевым данным
MOEX AlgoPack, среды обучения с подкреплением, ансамбль RL-агентов, модуль
статистического арбитража, факторные модели с ML-фильтрацией сигналов, модели
микроструктуры рынка (градиентный бустинг и рекуррентная нейросеть),
риск-контур с лимитами и аварийной остановкой, веб-дашборд мониторинга и
исполнение сделок в песочнице брокера. Проведено сравнительное исследование
шести классов стратегий на исторических данных 2021–2026 гг. с использованием
строгой методологии валидации.

## Цель и задачи

**Цель** — исследовать применимость методов машинного обучения (в первую
очередь обучения с подкреплением) для систематической торговли на MOEX и
разработать программную систему полного цикла: данные → модель → проверка →
исполнение.

**Задачи:** (1) реализовать инфраструктуру получения рыночных данных;
(2) построить торговые среды и обучить RL-агентов (PPO, SAC, A2C, DQN);
(3) реализовать альтернативные классы стратегий для сравнения; (4) обеспечить
методологически корректную оценку (walk-forward, контроль переобучения,
транзакционные издержки); (5) реализовать контур исполнения с управлением
рисками; (6) сформулировать выводы о наличии извлекаемой неэффективности.

## Методы

**Обучение с подкреплением.** Среды в стандарте Gymnasium: одноактивная
(дискретные действия лонг/шорт/кэш) и портфельная (непрерывные веса активов);
вознаграждение — дифференциальный коэффициент Шарпа со штрафами за оборот и
просадку. Алгоритмы PPO, SAC, A2C, DQN (Stable-Baselines3); ансамбль с
агрегацией по коэффициенту Шарпа на валидации.

**Статистический арбитраж.** Отбор коинтегрированных пар (тест
Энгла–Грейнджера), торговля возвратом спреда к среднему по z-оценке,
портфель пар с ограничением концентрации.

**Факторные модели.** Кросс-секционный моментум, недельный разворот, аномалия
низкой волатильности; volatility targeting; режимный фильтр по 200-дневной
средней; мета-лейблинг (Лопес де Прадо) — градиентный бустинг, предсказывающий
успех каждого сигнала базовой стратегии.

**Микроструктура рынка.** Признаки дисбаланса потока заявок (order flow
imbalance, Cont/Kolm), дисбалансы стакана, поток агрессивных сделок; данные —
собственный коллектор стакана (10 уровней, реальное время) и исторические
5-минутные микроданные MOEX AlgoPack за 6 месяцев. Модели: градиентный
бустинг и рекуррентная сеть (GRU) по последовательностям.

**Методология проверки** (ключевой элемент работы): разделение выборок строго
по времени; walk-forward-анализ (модель каждой недели/дня обучается только на
прошлом); оценка вероятности переобучения бэктеста PBO методом CSCV
(Bailey/López de Prado); учёт комиссий, спреда и проскальзывания в каждой
метрике; сравнение с пассивными бенчмарками; критерии успеха фиксируются до
эксперимента.

## Основные результаты

| № | Класс стратегий | Данные | Результат вне выборки |
|---|---|---|---|
| 1 | RL-ансамбль (направленная торговля) | свечи, 1 ч | устойчиво убыточен (−28…−69%), хуже пассивного бенчмарка |
| 2 | Парный арбитраж (коинтеграция) | свечи, 1 ч и 1 д | ≈ 0: преимущество in-sample не переносится на будущее |
| 3 | Моментум + vol-targeting + режимный фильтр | свечи, 1 д | +8.6% против +1.9% у рынка за 4.5 года; Шарп 0.23 |
| 4 | Мета-лейблинг поверх моментума | свечи, 1 д | сокращает убыток базовой стратегии в 3.5 раза (−19.5%→−5.6%); подтверждает ценность ML-фильтрации |
| 5 | Лонг-шорт моментум (маркет-нейтральный) | свечи, 1 д | ≈ 0 |
| 6 | Микроструктура: OFI-модели | AlgoPack, 6 мес; 25 недель walk-forward | **обнаружен статистически устойчивый сигнал: AUC 0.565, выше порога 0.55 в 21 из 25 недель**; однако величина (~1–1.5 б.п.) ниже транзакционных издержек (~4 б.п.) на всех горизонтах 5–60 мин |

## Выводы

1. Направленное применение RL к ценовым рядам ликвидных акций MOEX не
   обеспечивает положительной доходности вне выборки: в свечных данных
   отсутствует устойчивая закономерность, пригодная для извлечения.
2. Роль машинного обучения в торговых системах — фильтрация и калибровка
   сигналов, а не их генерация «из шума»: мета-лейблинг доказуемо улучшает
   риск-профиль базовой стратегии.
3. В микроструктуре рынка (поток заявок) обнаружена реальная краткосрочная
   предсказуемость, устойчивая на протяжении полугода. Это содержательный
   эмпирический результат работы.
4. Обнаруженная неэффективность не извлекается при розничных транзакционных
   издержках — её монетизация требует инфраструктуры маркет-мейкинга.
   Таким образом, слабая форма эффективности MOEX для розничного участника
   подтверждается «конструктивно»: систематическим перебором классов
   стратегий с корректной валидацией.
5. Практическая ценность: создана переиспользуемая инфраструктура
   (сбор данных, валидация, риск-контур, дашборд, песочница), пригодная для
   проверки новых гипотез и учебных задач.

## Архитектура системы

```
Данные:  Invest API Т-Банка (свечи, стакан RT, песочница) · MOEX AlgoPack (история микроструктуры) · новостные RSS
Модели:  RL-ансамбль · коинтеграция · факторы+мета-ML · бустинг/GRU по микроструктуре
Проверка: walk-forward · PBO · издержки · бейзлайны
Исполнение: риск-лимиты, kill-switch, режимы manual/semi/auto · песочница брокера
Мониторинг: веб-дашборд (Streamlit) · Telegram-уведомления · systemd-сервисы 24/7
```

## Структура репозитория

- `src/` — библиотека: среды RL (`env/`), агенты (`agent/`), арбитраж
  (`pairs/`), факторы (`factor/`), микроструктура (`lob/`), исполнение и риск
  (`live/`), валидация (`backtest/`), аналитика, новости, уведомления;
- `scripts/` — пронумерованные эксперименты (00–42), воспроизводящие все
  результаты таблицы выше;
- `dashboard/` — веб-интерфейс мониторинга;
- `docs/` — архитектурные документы, обзор литературы с источниками
  (`EDGE_ARCHITECTURE.md`), инструкции (`QUICKSTART.md`).

## Воспроизведение

См. `docs/QUICKSTART.md` (установка) и `docs/README_DEV.md` (карта скриптов).
Все эксперименты запускаются одной командой каждый; для доступа к данным
требуются бесплатный токен Invest API Т-Банка и подписка MOEX AlgoPack.
